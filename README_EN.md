# Division Ceremony

[中文](README_CN.md) | [Back](README.md)

**Division Ceremony** is a Minecraft NeoForge 1.21.1 mod that brings the *Unstable Ingot* and its related items from the classic mod **Extra Utilities** to modern Minecraft versions, with various enhancements and new mechanics.

## Features

- 🔸 **Unstable Ingot** — Crafted with diamond, division sigil, and gold ingot. Explodes after a configurable timer if not used in time.
- 🔸 **Mobius "Unstable/Stable" Ingot** — An enchanted ingot used to upgrade tools via smithing table.
- 🔮 **Division Ritual** — Activate a beacon at midnight, defeat waves of mobs to transform a Division Sigil into a Pseudo-Inversion Sigil.
- ⛏ **Destruction Pickaxe** — 5× mining speed on stone, upgradable with Mobius Ingot.
- 🔸 **Erosion Shovel** — Fast on soft blocks, clears sand/gravel above.
- 🪓 **Healing Axe** — Restores hunger over time, heals non-undead targets on hit.
- ⚔ **Etheric Sword** — Deals magic damage that bypasses armor.
- 🚿 **Reinforced Watering Can** — Right-click and hold to rapidly grow crops and saplings in a 9×9 area.
- 💎 **Soul Fragment** — Sacrifice health to craft, consume to restore it.
- ⚙ **Configuration** — Full Cloth Config support with in-game config screen.
