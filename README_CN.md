# 分割仪式

[English](README_EN.md) | [返回](README.md)

**分割仪式** 是一个 Minecraft NeoForge 1.21.1 模组，将经典模组 **Extra Utilities** 中的*不稳定金属锭*及其相关物品复刻到了高版本，并做了一些改动和扩展。

## 特性

- 🔸 **不稳定金属锭** — 钻石 + 分割徽章 + 金锭合成，限时使用否则爆炸。
- 🔸 **莫比乌斯"稳定/不稳定"锭** — 附魔光效，用于锻造台升级工具。
- 🔮 **分割仪式** — 午夜右键信标，击杀波次怪物将分割徽章转化为伪逆徽章。
- ⛏ **毁灭之镐** — 石头 5 倍速，可用莫比乌斯锭升级获效率 X + 时运 X。
- 🔸 **侵蚀之铲** — 软方块速掘，自动清除上方沙砾。
- 🪓 **治愈之斧** — 手持回复饱食度，攻击非亡灵给予生命恢复。
- ⚔ **天域之剑** — 魔法伤害无视护甲。
- 🚿 **强化洒水壶** — 长按右键 9×9 范围催熟作物和树苗。
- 💎 **灵魂碎片** — 合成扣除血量上限，右键消耗恢复。
- ⚙ **可配置** — Cloth Config 配置界面，支持中文。
